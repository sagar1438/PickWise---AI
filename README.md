# PickWise - AI

Find the right AI model for your project.

PickWise is a full-stack AI model discovery and recommendation platform that helps users find suitable models based on their project requirements, budget, priorities, and required capabilities.

## Tech Stack

- Frontend: React, Vite, JavaScript, React Router
- Backend: Python, FastAPI, SQLAlchemy
- Database: SQLite
- AI Integration: Google Gemini API
- Background: Three.js animated shader

## Features

- Discover and search AI models
- Explore trending models and new releases
- Compare multiple models side by side
- Get personalized model recommendations
- View model capabilities and performance metrics
- AI-generated recommendation explanations
- Animated background and responsive interface
